# **Web Development Foundations**

## **Introduction to the Web**

### **What is the Internet?**

*The Internet is a worldwide network of interconnected computers and devices that communicate with each other and share information.*

**Examples:**

- *Watching YouTube videos*
- *Sending WhatsApp messages*
- *Browsing Google*
- *Sending emails*
- *Using Instagram*
- *Attending online classes/meetings*

*All these activities use the Internet*

---

**How does the Internet work?**

*Suppose you open Google in your browser*

- *You open Google Chrome*
- *You enter ```www.google.com```*
- *Your browser sends a request through the Internet*
- *Google's server receives your request*
- *The server processes the request and sends information back*
- *Your browser displays the Google webpage*

---

### **What is the World Wide Web (WWW)?**

*The World Wide Web is a collection of interconnected webpages and websites that we access through the Internet.*

**Examples:**

- *Google*
- *Amazon*
- *Wikipedia*
- *YouTube*

*The Internet and WWW are not the same thing.*

---

### **What is a Website?**

*A website is a collection of related web pages connected together under a common domain name and accessible through the Internet.*

**Examples:**

- *Google*
- *Wikipedia*
- *Amazon*
- *YouTube*

*Consider an educational website*
- *Home*
- *About Us*
- *Courses*
- *Contact Us*
- *Login*

*Each of these can be an individual webpage. Together they form a website*

---

### **What is a Webpage?**

*A webpage is a single document on the World Wide Web that can be viewed using a web browser.*

*For example, When you open the About Us page of a college website, you are viewing one webpage.*

*A webpage can contain*
- *Text*
- *Images*
- *Videos*
- *Links*
- *Tables*
- *Forms*
- *Buttons*
