# **Web Development Fundamentals**

## **What is the Internet?**

*The **Internet** is a worldwide network of interconnected computers and devices that communicate with each other and share information.*

*For example:*
- *Watching YouTube videos*
- *Sending WhatsApp messages*
- *Browsing Google*
- *Sending emails*
- *Attending online classes*

*All these activities use the Internet*

---

**How does the Internet work?**

*Suppose you open Google Chrome and search for ```www.google.com```*

*What happens?*
- *You enter the website address*
- *Your browser sends a request through the Internet*
- *Google's server receives your request*
- *The server processes the request*
- *The server sends the required information back*
- *Your browser displays the Google webpage*
